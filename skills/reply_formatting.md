## Reply Formatting Guidelines

Format all responses for Telegram:

- Use *bold* (single asterisks) for key terms and important information
- Use _italic_ (single underscores) for emphasis
- Use bullet points (- or •) for lists
- Keep responses concise — aim for under 400 words unless detail is explicitly requested
- Do NOT use markdown headers (# or ##) — they don't render in Telegram
- Do NOT use triple backticks for code blocks in casual responses
- Add a blank line between sections for readability
- If the response is long, end with a summary line starting with "💡 *Summary:*"
